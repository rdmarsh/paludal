# Paludal

A dozenal (base-12) system of units: as rigorous as SI, with every unit defined by a fixed constant and
converting exactly to SI, but sized for everyday human use.

- `ideas.md` - the spec: every decision and why it was made
- `index.html` - quick-view page of the spec, generated by `make` (GNU make 4.4+; `gmake` on macOS)
- `make all` also builds DocBook, LaTeX, PDF (memoir, with dozenal page and section numbers) and AsciiDoc into `out/`. Everything comes from `ideas.md`
  through pandoc and one filter, `pandoc/paludal.lua`; see the `Makefile` for what each format needs
- `blinker/` - a terminal Paludal clock that sounds the blink, beat and breath: `cd blinker && go run .`

Read the spec online at https://rdmarsh.github.io/paludal/, or download the PDF from the latest release:
https://github.com/rdmarsh/paludal/releases/latest/download/paludal.pdf

GitHub Pages serves `index.html` from `main`, so run `make` and commit `index.html` with every change to
`ideas.md`. To release a version: update the Version line and the Versions list in `ideas.md`, then
`make all`, commit, tag (`git tag -a vX.Y`), push, and `gh release create vX.Y out/paludal.pdf`.
