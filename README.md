# Paludal

A dozenal (base-12) system of units: as rigorous as SI, with every unit defined by a fixed constant and
converting exactly to SI, but sized for everyday human use.

- `spec/` - the spec: every decision and why it was made, one Markdown file per chapter. Files are read in
  name order: `2-04-time.md` is chapter 4 of Part 2, and `2-00-...` holds the part's opening text
- `docs/` - the website, one page per chapter, generated by `make` (GNU make 4.4+; `gmake` on macOS)
- `make all` also builds DocBook, LaTeX, PDF (memoir, with dozenal page and section numbers) and AsciiDoc into `out/`. Everything comes from `spec/`
  through pandoc and one filter, `pandoc/paludal.lua`; see the `Makefile` for what each format needs
- `blinker/` - a terminal Paludal clock that sounds the blink, beat and breath: `cd blinker && go run .`

Read the spec online at https://paludal.org, or download the PDF from the latest release:
https://github.com/rdmarsh/paludal/releases/latest/download/paludal.pdf

GitHub Pages serves `docs/` from `main`, so run `make` and commit `docs/` with every change to
`spec/`. To release a version: update the Version line in `spec/0-00-index.md` and the Versions list in
`spec/4-02-versions.md`, then
`make all`, commit, tag (`git tag -a vX.Y`), push, and `gh release create vX.Y out/paludal.pdf`.
